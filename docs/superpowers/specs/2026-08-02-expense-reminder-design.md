# เตือนบันทึกค่าใช้จ่ายสำคัญบนกระดิ่ง — ค่ามือหมอ + เงินเดือนพนักงาน

**เป้าหมาย:** พนักงานชอบลืมบันทึกค่าใช้จ่ายรอบใหญ่ → กระดิ่งในแอปเตือนตั้งแต่วันถัดจากวันจ่าย ค้างจนกว่าจะบันทึกจริง แล้วหายเอง (ไม่มีปุ่มปิด — ผูกกับข้อมูลจริง)

**อนุมัติ:** 2026-08-02 · ช่องทางเดียวกับแถบวันเกิด ([2026-08-02-birthday-reminder-design.md](2026-08-02-birthday-reminder-design.md)) — ไม่มี LINE ไม่มี cron

|---|---|---|---|

## กติกา "บันทึกแล้ว = หาย"

เตือนของรอบครบกำหนด D (รอบล่าสุดที่ผ่านมาแล้ว) หายเมื่อมีรายการในหมวดนั้นที่ `expense_date ≥ D-3` **และ `amount ≥ 10,000`** — เกณฑ์ยอดกันรายการแทรกยิบย่อย (พบจริง: เบิกย่อย 2,500–5,750 กลางรอบ ขณะที่รอบใหญ่ 28,000–52,000) ไปปิดเตือนทั้งที่รอบใหญ่ยังไม่ลง · ขอบหน้าต่าง D-3 รองรับพฤติกรรมลงจริงคลาดวัน (รอบ 20 เคยลงวันที่ 21, สิ้นเดือนลง 30/31)

แสดงเฉพาะรอบครบกำหนดล่าสุดต่อหนึ่งงาน (รอบใหม่มาแทนรอบเก่าที่ค้าง) · ไม่จำกัดวันหมดอายุ — ค้างจนกว่าจะบันทึกหรือรอบถัดไปมาถึง

## หน้าตา

- ป้ายตัวเลขกระดิ่ง = คิวรออนุมัติ + วันเกิด + **จำนวนเตือนค่าใช้จ่าย**
- แถบเหลือง (amber) ในกล่องกระดิ่ง ใต้แถบวันเกิด ลิงก์ไป `/expenses`:
  - `💰 อย่าลืมบันทึกค่ามือหมอ รอบวันที่ 20 ก.ค.` / `รอบสิ้นเดือน ก.ค.`
  - `💼 อย่าลืมบันทึกเงินเดือนพนักงาน เดือน ก.ค.`
- ไม่มีเสียง/toast/realtime — สดตอนโหลด/เปลี่ยนหน้า (เหมือนวันเกิด)

## เทคนิค

- `src/lib/expense-reminders.ts`:
  - pure (TDD): `lastTherapistDue(todayIso)` / `lastSalaryDue(todayIso)` คืนวันครบกำหนดล่าสุดที่ < วันนี้ (เดือนสั้น-ยาว/ข้ามปีต้องถูก) + ตัวประกอบข้อความ
  - `expenseReminders(supabase, todayIso)` — เช็คตาราง expenses ตามกติกาข้างบน คืนลิสต์เตือน
- `(app)/layout.tsx` เรียกเพิ่มใน `Promise.all` เดิม → ส่งเข้า provider → กระดิ่งวาด
- ไม่มี migration · หมวดอิงชื่อ category ตรงตัวที่พนักงานใช้จริง (ถ้าร้านเปลี่ยนชื่อหมวดต้องแก้ค่าคงที่ตาม)

## ทดสอบ

- unit: วันครบกำหนดรอบ 10/20/สิ้นเดือน ครอบเดือนสั้น (ก.พ.) ข้ามเดือน ข้ามปี · ข้อความ
- E2E จริงทันทีหลัง deploy: วันนี้ 2 ส.ค. — ค่ามือหมอรอบสิ้นเดือน ก.ค. และเงินเดือน ก.ค. ยังไม่ถูกบันทึก (ล่าสุด 21 ก.ค. / 30 มิ.ย.) → ต้องเห็นเตือน 2 แถบจริง
