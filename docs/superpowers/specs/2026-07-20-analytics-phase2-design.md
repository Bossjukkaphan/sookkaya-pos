# SOOKKAYA POS — การเงินและจุดคุ้มทุน (เฟส 2)

วันที่: 2026-07-20
สถานะ: รอผู้ใช้อนุมัติ

## ที่มา

เฟส 1 วางรากฐานไว้ครบแล้ว — แยกประเภทต้นทุน, ต้นทุนวัสดุต่อเมนู, และ view
`v_daily_summary` / `v_therapist_daily` ที่เป็นแหล่งความจริงเดียวของสูตร

เฟสนี้เอารากฐานนั้นมาสร้างหน้าการเงินที่ตอบคำถาม 3 ข้อของเจ้าของร้าน:

1. เดือนนี้ได้กำไรเท่าไหร่ และเงินสดเข้าจริงเท่าไหร่ (คนละตัวเลข)
2. ต้องทำกี่เซสชันถึงคุ้มทุน
3. เมนูไหนขายดีแต่กำไรน้อย

## ข้อตกลงที่ตัดสินไว้แล้วในเฟส 1 (ไม่ต้องถามซ้ำ)

| เรื่อง | ข้อตกลง |
| ------ | ------- |
| นิยามกำไร | แสดง 2 ตัว — เงินสดจริง (สูตร Excel) เป็นหลัก, กำไรเชิงบัญชีเป็นรอง |
| Net Revenue | ยอดที่รับรู้เสมอ (`revenue_recognize`) ตัดส่วนโบนัสสมาชิกออก |

| เป้ารายเดือน | `settings.monthly_target` = 400,000 |

## สิ่งที่จะสร้าง

### 1. `v_monthly_pl` — view สรุปรายเดือน

```
month · net_revenue · cash_in · sessions
commission_cost · fixed_cost · variable_cost · onetime_cost · payroll_paid
```

- `commission_cost` มาจาก `v_therapist_daily` (รวมประกันแล้ว)
- `payroll_paid` = รายจ่ายหมวด HR/payroll ที่จ่ายจริง แยกออกมาเพื่อ**ไม่ให้หักซ้ำ**
  กับ `commission_cost` — เป็นบั๊กที่เคยเจอมาแล้ว
- ทุกอย่างเป็นรายเดือน ไม่ใช่รายวัน เพราะรายจ่ายบันทึกเป็นก้อน

### 2. หน้า `/finance` — การเงินรายเดือน

**ส่วนที่ 1 — กำไร 2 มุมมองคู่กัน**

```
เงินสดจริง (แบบ Excel)          กำไรเชิงบัญชี
รายได้รับรู้      347,018        รายได้รับรู้        347,018
− รายจ่ายทั้งหมด  258,027        − ค่ามือที่เกิดขึ้น   140,415
                                 − รายจ่ายอื่น       106,777
= 88,991                         = 99,826
```

พร้อมคำอธิบายสั้นๆ ว่าต่างกันเพราะจังหวะจ่ายเงินไม่ตรงเดือน

**ส่วนที่ 2 — เตือนเมื่อข้อมูลเดือนยังไม่ครบ** ⚠️ สำคัญ

รายจ่ายก้อนใหญ่ (ค่าเช่า เงินเดือน) บันทึกตอนสิ้นเดือน ทำให้ต้นเดือนกำไรดูสูงเกินจริง

ตัวอย่างจริง ณ 20 ก.ค.: ต้นทุนคงที่บันทึกแล้วแค่ **฿2,636** เทียบกับ มิ.ย. **฿104,648**
ทำให้กำไรแสดง **+121,175** ทั้งที่ยังไม่ได้หักค่าเช่าและเงินเดือน

**กฎ:** ถ้าต้นทุนคงที่ของเดือนที่ดูอยู่ < 50% ของค่าเฉลี่ย 3 เดือนก่อนหน้า
ให้ขึ้นแถบเตือนสีเหลืองว่า *"ยังบันทึกรายจ่ายไม่ครบ กำไรที่เห็นสูงกว่าความจริง"*
พร้อมบอกว่าปกติเดือนหนึ่งมีต้นทุนคงที่ประมาณเท่าไหร่

**ส่วนที่ 3 — เทียบเป้า** แถบความคืบหน้าเทียบ `monthly_target`

**ส่วนที่ 4 — P&L ย้อนหลัง 6 เดือน** ตารางรายเดือน

**ส่วนที่ 5 — รายจ่ายแยกประเภท** fixed / variable / onetime พร้อมสัดส่วน

### 3. หน้า `/finance/unit-economics` — จุดคุ้มทุน

- รายได้เฉลี่ย/เซสชัน · ต้นทุนผันแปร/เซสชัน · กำไรที่ได้เพิ่มทุกเซสชัน
- **จุดคุ้มทุน 2 แบบ** — คุ้มต้นทุนคงที่อย่างเดียว / คุ้มรวม one-time ด้วย
  (ตามที่ตกลงว่าไม่ควรหลอกตัวเองด้วยตัวเลขที่ไม่รวมการตลาด)
- กำไรต่อเมนู: ราคา − ค่ามือ − ต้นทุนวัสดุ เรียงจากน้อยไปมาก
  เพื่อหาเมนูที่ขายดีแต่กำไรบาง

### 4. หน้าตั้งค่าจัดกลุ่มต้นทุน

เพิ่มแท็บใน `/settings` ให้แก้ `expense_category_types` และแก้ `cost_type`
รายรายการได้ — เพราะกฎเดาจากชื่อรายการไม่มีวันครอบคลุมทุกกรณี
(ตอน backfill ต้องแยกเงินเดือน reception ออกจากค่ามือด้วยคำสำคัญ)
