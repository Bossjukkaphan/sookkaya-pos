# SOOKKAYA POS — จัดหน้ายอดวันนี้ใหม่ (ลำดับ + หน้าตารายการขาย)

วันที่: 2026-07-22
สถานะ: รออนุมัติ

## ที่มา

หน้า `/today` (ยอดขายวันนี้) ตอนนี้วางรายการขายไว้ล่างสุด ต้องเลื่อนผ่านสรุปหลายอันกว่าจะเห็น
และหน้าตาแต่ละรายการเป็นข้อความเรียงกันจางๆ อ่านยากเวลามีหลายรายการ

เจ้าของร้านอยากให้รายการขายขึ้นมาอยู่บน (หลังการ์ดสรุป) และตกแต่งให้อ่านง่าย

## ขอบเขต

งานนี้เป็น **display-only** — ไม่แตะ logic เงิน ไม่แตะ query ไม่แตะฐานข้อมูล
แค่สลับลำดับ block และเปลี่ยน markup ของแต่ละรายการ

**นอกขอบเขต:** เปลี่ยนตัวเลข/สูตร · เพิ่มฟีเจอร์ค้นหา/กรอง · แตะหน้าอื่น

## หน้าตาแต่ละรายการ (component `SaleRow`)

โครง flex เหมือนเดิม (เวลา ซ้าย · เนื้อหา กลาง · ยอดเงิน+ปุ่ม ขวา) แต่จัดใหม่:

- **เวลา** — คอลัมน์ซ้าย ตัวหนา `tabular-nums text-slate-400` (แทนที่จะปนอยู่ในบรรทัดกลาง)
- **เมนู** — ตัวหนา ตามด้วย badge:
  - รีเควส → `variant="outline"` เล็ก
  - สมาชิก (`member_status`) → badge สีม่วง `bg-violet-600` (เดิมเป็นสี default)
- **บรรทัดลูกค้า · หมอ** — `👤 {ลูกค้า} · {หมอ}` (เพิ่มไอคอน)
- **แถวรายละเอียด** (แถวเดียว flex-wrap): badge ช่องทางชำระเป็นสี + `ค่ามือ X ฿` + ถ้ามีส่วนลด `ลด X (โปรฯ)` สีชมพู
- **ยอดเงิน** — `text-lg font-bold text-emerald-800` ขวา ตามด้วยปุ่มแก้/ลบเมื่อ `editable`

### สีช่องทางชำระ

| ช่องทาง | สี |
| ------- | -- |
| QR Code | ฟ้า (`bg-sky-100 text-sky-700`) |

| Gowabi · KOL · ไม่ระบุ (default) | เทา (`bg-slate-100 text-slate-600`) |

## ความถูกต้องที่ต้องรักษา

- ตัวเลขทุกตัวมาจากแหล่งเดิม ไม่คำนวณใหม่
- ปุ่มแก้/ลบโผล่เฉพาะ `editable` (ทั้งช่วงวันอยู่ในเดือนปัจจุบัน) เหมือนเดิม
- โหมดช่วงวัน (จัดกลุ่มตามวัน หัววัน sticky) ยังทำงาน — `SaleRow` ใช้ร่วมทั้งสองโหมด
- ราคาปกติ/ส่วนลดโชว์เฉพาะเมื่อมีส่วนลด (กันซ้ำกับยอดสุทธิ) — กติกาเดิม
