# รวม "ดูแลลูกค้า" + "ลูกค้าและคนที่หายไป" เป็นเมนูเดียว

**เป้าหมาย:** สองเมนูโชว์ "ลูกค้าหายไปนาน" ซ้ำกัน (ต่างแค่มุมลงมือ vs มุมวิเคราะห์) → เหลือเมนูเดียว "ดูแลลูกค้า" มี 2 แท็บ · อนุมัติ 2026-08-02 — Boss สั่ง "รวมแค่นี้ก่อน" จากผลไล่ตรวจเมนูทั้งระบบ (แผนใหญ่ 19→11 เมนูรอเฟสถัดไป)

## โครงใหม่ของ /crm

- **แท็บ "ต้องติดต่อวันนี้"** (default) — เนื้อหา /crm เดิมทั้งหมด ไม่แตะพฤติกรรม (ทุก role)
- **แท็บ "วิเคราะห์ลูกค้า"** — เนื้อหา /insights/customers เดิมทั้งหมด: ยอดสะสมสูงสุด 50 / หายไปนาน 30-60-90 วัน (เฉพาะ manager+ — role ต่ำกว่าไม่เห็นแท็บ และเข้าตรงเจอ InsightsAccessDenied เหมือนเดิม)
- URL: `/crm` = แท็บแรก · `/crm?tab=insights&sub=ltv|dormant&days=N` = แท็บสอง · พารามิเตอร์ `gone` ของแท็บแรกคงเดิม

## การย้าย

- ย้าย JSX ของ insights/customers ไปเป็น component `src/app/(app)/crm/customer-insights.tsx` (server) — โค้ดเดิมยกมาทั้งก้อน เปลี่ยนเฉพาะ href ภายในให้ชี้ /crm
- `/insights/customers/page.tsx` → `redirect("/crm?tab=insights&…")` map พารามิเตอร์เดิม (แบบเดียวกับ /sales → /reports ที่มีอยู่แล้ว) — ลิงก์เก่า/bookmark ไม่ตาย
- `nav.ts`: ลบรายการ "ลูกค้าและคนที่หายไป" · อัปเดตคำอธิบาย "ดูแลลูกค้า" ให้ครอบวิเคราะห์ด้วย
- ลิงก์ในหน้าภาพรวม → `/crm?tab=insights`
