# เตือนบิลประจำค่าน้ำ/ค่าไฟ/เน็ต บนกระดิ่ง — design

วันที่ 23 สิงหาคม 2569 · ต่อยอดจาก [2026-08-02-expense-reminder-design.md](2026-08-02-expense-reminder-design.md)

## ปัญหา

กระทบยอดหมวด `ค่าน้ำ / ค่าไฟ / Internet` (23/8/2569) พบบิลรอบ ก.ค. หายสองใบ
โดยไม่มีอะไรฟ้อง: **ค่าน้ำ** (จ่ายคู่ค่าไฟทุกเดือน แต่ 28/7 มีแต่ค่าไฟ) และ
**บิลเน็ตหนึ่งรอบ** (จังหวะจ่าย 7/4 · 8/5 · 12/6 · *ข้าม* · 1/8)
ระบบเตือนบนกระดิ่งเดิมครอบแค่ค่ามือหมอกับเงินเดือน — เจ้าของร้านอนุมัติให้เพิ่ม
บิลประจำสามตัวนี้ด้วยกลไกเดียวกัน (เตือนค้างจนกว่าจะบันทึกจริง ไม่มีปุ่มปิด)

## จังหวะจ่ายจริง (สำรวจข้อมูล มี.ค.–ส.ค. 2569)

สามบิลอยู่หมวดเดียวกัน แยกกันด้วยขนาดเงินกับชื่อรายการ:

| บิล | ยอดจริง | วันจ่ายจริง | ครบกำหนด | เกณฑ์ "บันทึกแล้ว = เตือนหาย" |
|---|---|---|---|---|
| ค่าไฟ | 2,847–17,701 | 21–30 ของเดือน | สิ้นเดือน | ยอด ≥ 2,500 ตั้งแต่ D−10 |
| ค่าน้ำ | 70–165 | คู่กับค่าไฟ | สิ้นเดือน | ชื่อรายการขึ้นต้น "ค่าน้ำ" ตั้งแต่ D−10 |
| เน็ต/โทรศัพท์ | 462–2,197 (ซิม EDC 136 ไม่นับ) | 1–12 ของเดือนถัดไป | วันที่ 12 | ยอด ≥ 400 และ < 2,500 ตั้งแต่ D−11 |

เกณฑ์ 2,500 คั่นค่าไฟ (ต่ำสุด 2,847) จากบิลอื่น (สูงสุด 2,197) · เกณฑ์ 400 คั่นเน็ต
(ต่ำสุด 462) จากค่าน้ำ/ซิม EDC (สูงสุด 165/136) · ค่าน้ำยอดเล็กเกินกว่าจะแยกด้วยเงิน
จึงใช้ชื่อรายการซึ่งพนักงานตั้งว่า "ค่าน้ำ" เหมือนกันทุกครั้ง (4/4 ครั้ง)

## กติกาที่คงเดิมจาก spec แม่

เตือนเฉพาะรอบครบกำหนดล่าสุดที่**ผ่านมาแล้ว** (วันครบกำหนดพอดียังไม่เตือน) ·
แถบเหลืองบนกระดิ่งลิงก์ไป `/expenses` · ไม่มี LINE ไม่มี cron · หายเองเมื่อมีรายการเข้าเกณฑ์

ข้อความ: `💡 อย่าลืมบันทึกค่าไฟ เดือน ก.ค.` · `🚰 อย่าลืมบันทึกค่าน้ำ เดือน ก.ค.` ·
`🌐 อย่าลืมบันทึกค่าเน็ต/โทรศัพท์ร้าน รอบต้นเดือน ส.ค.`

## เทคนิค

- `src/lib/expense-reminders.ts` — duty ใหม่ 3 ตัว + `lastUtilityDue` / `lastInternetDue`
  \+ label · โครงเกณฑ์เปลี่ยนเป็นตาราง `DutyCheck` (category · window · min/max · item prefix)
- migration `20260823060000_utility_bill_reminders.sql` — `layout_bootstrap` เวอร์ชันใหม่
  CTE duties เป็นตารางเกณฑ์โครงเดียวกับ `DutyCheck` — กติกาสองภาษาต้องแก้คู่กันเสมอ
- `src/lib/layout-bootstrap.ts` — คัด duty ที่ app ไม่รู้จักทิ้ง กันช่วง SQL ใหม่กว่า app
  ได้ label ผิดงาน
- ไม่แตะ UI — กระดิ่ง (`queue-notifications.tsx`) วาดจากลิสต์เดิมอยู่แล้ว

## ตรวจของจริงหลัง deploy

วันนี้ (23/8) ต้องเห็นเตือน **🚰 ค่าน้ำ เดือน ก.ค.** หนึ่งแถบ (ใบที่หายจริง) ส่วนค่าไฟ
(คีย์ 28/7) กับเน็ต (คีย์ 1/8) ต้องเงียบ — เป็น E2E ของกติกาทั้งขาเตือนและขาหาย

## จุดเปราะที่รู้อยู่

- เกณฑ์เงินอิงช่วงยอดจริงวันนี้ — ถ้าบิลไฟลดต่ำกว่า 2,500 หรือค่าเน็ตขึ้นเกิน 2,500
  จะเตือนหลอก/ไม่เตือน แก้ที่ค่าคงที่สองที่ (TS + SQL)
- พนักงานเปลี่ยนวิธีตั้งชื่อ "ค่าน้ำ" → เตือนค่าน้ำค้างไม่หาย (เห็นแล้วจะรู้เอง ไม่เงียบผิดทาง)
