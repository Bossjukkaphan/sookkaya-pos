# ศูนย์ดูแลลูกค้า /crm — ระบบชงงาน คนลงมือ (CRM แนวทาง 1)

**เป้าหมาย:** เปิดหน้าเดียวรู้เลยว่า "วันนี้ควรติดต่อใคร เพราะอะไร" — ดึงลูกค้าเก่ากลับ + อวยพรวันเกิด + ตามลูกค้าใหม่ · แอดมิน/ผู้จัดการใช้บนมือถือ โทร/ทักเองตามลิสต์ แล้วบันทึกผลกันติดต่อซ้ำซ้อน

## ลิสต์ชงอัตโนมัติ 3 ประเภท (จาก v_customer_ltv + customers)

1. **🎂 วันเกิด** — ลูกค้าที่มี birthday ตกใน 7 วันข้างหน้า (รวมวันนี้ ข้ามปีได้)
2. **💤 หายไปนาน** — มาแล้ว ≥ 2 ครั้ง แต่ last_visit เกิน 30/60/90 วัน (แท็บเลือก, ค่าตั้งต้น 60) เรียงยอดสะสมมาก่อน — คนสำคัญขึ้นก่อน
3. **🌱 ลูกค้าใหม่** — มาครั้งแรกครั้งเดียว เมื่อ 5-14 วันก่อน (โทรตามผล ชวนกลับ)

ทุกลิสต์: เฉพาะคนมีเบอร์ · ตัดคนที่ถูกบันทึกผลในลิสต์ประเภทเดียวกันภายใน 30 วันออก (กันติดต่อซ้ำ) · เพดาน 30 คน/ลิสต์

## ต่อรายชื่อ

ชื่อ (+ชื่อเล่น) · เบอร์ · เหตุผล (วันเกิด X / หายไป Y วัน · ยอดสะสม Z) · ปุ่ม **โทร** (tel:) · ปุ่ม **คัดลอกข้อความ** (เทมเพลตตามประเภท ใส่ชื่อให้) · ปุ่ม **บันทึกผล**: ติดต่อแล้ว-รอตอบ / จองแล้ว 🎉 / ไม่สะดวก / เบอร์ผิด → แถวหายจากลิสต์ทันที

## ข้อมูล

`crm_contacts` (id, customer_id FK, list_type: birthday|winback|new_follow, result, note null, created_by, created_at) · RLS authenticated อ่าน-เขียน · โปรไฟล์ลูกค้าโชว์ประวัติการติดต่อล่าสุด

## เทมเพลตข้อความ (lib/crm.ts — TDD)

วันเกิด / ชวนกลับ / ตามลูกค้าใหม่ — ภาษาอบอุ่นแบบร้าน ใส่ชื่อลูกค้า + ลิงก์จองคิว (https://liff.line.me/2010834662-8ao9hODH) · ไม่มีชื่อ → "คุณลูกค้า"
