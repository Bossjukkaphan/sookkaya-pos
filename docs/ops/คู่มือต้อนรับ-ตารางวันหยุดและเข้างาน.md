# คู่มือพนักงานต้อนรับ: ลงตารางวันหยุดล่วงหน้า + เช็คอินหน้างาน

อัปเดต 4 พ.ย. 2569 · สำหรับพนักงานต้อนรับที่รับหน้าที่ดูแลข้อมูลคนทำงานแทนผู้จัดการ

---

## 0. สองหน้านี้คือ "คนละระบบ" ต้องทำทั้งคู่

หลายคนเข้าใจผิดว่าลงที่เดียวแล้วจบ — ไม่ใช่ครับ ระบบเก็บแยกกันคนละตาราง และตอบคำถามคนละคำถาม

|  | 📅 **จัดวันหยุด** (`/shifts`) | ✅ **เข้างาน** (`/checkin`) |
| --- | --- | --- |
| ตอบคำถามว่า | **แผน** — ใครจะหยุด/ลาวันไหนในอนาคต | **ของจริง** — วันนี้ใครมาจริง มากี่โมง กลับกี่โมง |
| ลงเมื่อไหร่ | ล่วงหน้า เป็นสัปดาห์/เป็นเดือน | ทุกเช้าก่อนเปิดร้าน + ตอนกลับบ้าน |
| ใครลงได้ | ผู้จัดการ/แอดมิน | ทุกคนที่ล็อกอินเข้าระบบได้ |
| ลงแล้วมีผลกับ | ความจุรับจองไลน์ของวันอนาคต · กันลูกค้าจองหมอที่หยุด | บอร์ดคิววันนี้ · นับวันทำงาน/ชั่วโมง · ค่ามือ · ความจุจองของวันนั้น |
| ไม่ลงแล้วเกิดอะไร | ระบบคิดว่าหมอมาครบทุกคน → **รับจองเกินกำลัง** | หมอคนนั้นวางการ์ดคิวไม่ได้ · วันทำงานในหน้าทีมงานขาด |

> **จำสั้นๆ:** จัดวันหยุด = "แผนว่าใครจะไม่มา" · เข้างาน = "ยืนยันว่าใครมาแล้ว"

---

## 1. 📅 หน้า "จัดวันหยุด" — ลงแผนล่วงหน้า

### เข้าหน้านี้อย่างไร
- **มือถือ:** แถบล่าง → ปุ่ม **เพิ่มเติม** → หมวด *ผู้บริหาร* → **จัดวันหยุด 📅**
- **คอมพิวเตอร์:** แถบเมนูซ้าย → **จัดวันหยุด**

### วิธีลง
1. ปุ่ม **←  →** ด้านบนเลือกเดือน (ชื่อเดือนไทย + พ.ศ.)
2. ตารางคือ **รายชื่อคน × วันที่ของเดือน** หมอนวดอยู่กลุ่มบน ทีมงานอยู่กลุ่มล่าง
3. **แตะช่องวันของคนนั้น** เพื่อวนสถานะ:

   | แตะครั้งที่ | สถานะ | สีช่อง |
   | --- | --- | --- |
   | 1 | **หยุด** | เทา เขียนว่า "หยุด" |
   | 2 | **ลา** | เหลือง เขียนว่า "ลา" |
   | 3 | กลับเป็น **ทำงานปกติ** | ว่าง (ขาว) |

4. ช่องว่าง = ทำงานปกติ (ไม่ต้องกดอะไรสำหรับคนที่มาทำงาน)
5. กรอบสีม่วง = วันนี้

### ตัวช่วยที่ควรใช้
- **แถวล่างสุด "หมอทำงาน (คน)"** บอกกำลังพลของแต่ละวัน ถ้าตัวเลขเป็น **สีแดง** = วันนั้นคนบางที่สุดของเดือน ให้ระวังเรื่องรับคิว
- **ปุ่ม "จ. 2 / จ. 9 / จ. 16 …"** ด้านล่าง = คัดลอกแผนของสัปดาห์ก่อนหน้ามาใส่สัปดาห์นั้น
  ช่องที่ลงไว้แล้วจะไม่ถูกทับ (ปลอดภัย กดได้)
  ใช้ตอนวางแผนสัปดาห์ใหม่ → กดคัดลอกก่อน แล้วค่อยแก้เฉพาะวันที่ต่างจากเดิม

### กติกาการใช้ "หยุด" กับ "ลา" (ขอให้ใช้ให้ตรงกันทุกคน)
- **หยุด** = วันหยุดประจำ / วันที่ร้านจัดให้หยุด
- **ลา** = ลาป่วย ลากิจ ลาพักร้อน กลับบ้านต่างจังหวัด

ตอนนี้ในระบบมีแต่ "หยุด" ทั้งหมด **ยังไม่มีใครใช้ "ลา" เลยแม้แต่ครั้งเดียว** ทำให้ย้อนดูไม่ได้ว่าวันนั้นหยุดปกติหรือลา — ขอให้เริ่มแยกจากนี้ไป

### งานประจำที่ขอให้ทำ
| เมื่อไหร่ | ทำอะไร |
| --- | --- |
| ทุกเย็นก่อนปิดร้าน | ถามทีมว่า **พรุ่งนี้ใครไม่มา** → ลงในตารางให้ครบทันที |
| ทุกวันอาทิตย์ | วางแผน **สัปดาห์ถัดไป** ให้ครบ (กดปุ่มคัดลอกสัปดาห์ก่อน แล้วแก้ที่ต่าง) |
| ทันทีที่มีคนแจ้งลายาว | ลงเลยไม่ต้องรอ เช่น กลับบ้าน 7 วัน ลงให้ครบทั้ง 7 วัน |

### กดแล้วเกิดอะไรขึ้นทันที
1. ลูกค้าจองไลน์โดย **ระบุหมอคนนั้น** ในวันนั้น → ระบบปฏิเสธเองว่า *"หมอที่เลือกหยุดวันนั้นค่ะ เลือกหมอท่านอื่นหรือให้ร้านจัดให้นะคะ"*
2. **ความจุรับจอง** ของวันนั้นลดลง 1 คน (ระบบคำนวณ: หมอ active ทั้งหมด − คนที่วางแผนหยุด)
3. หน้า **เข้างาน** ของวันนั้นจะขึ้นป้าย 😴 *หยุดตามแผน* หรือ 🏖️ *ลา (ตามแผน)* ให้เห็น

## 2. ✅ หน้า "เข้างาน" — ยืนยันของจริงหน้างาน

### เข้าหน้านี้อย่างไร
- **มือถือ:** แถบล่าง → **เข้างาน ✅** (อยู่หมวดหน้าร้าน ทุกคนเข้าได้ ไม่ต้องเป็นผู้จัดการ)
- จากหน้าจัดวันหยุด มีปุ่ม **"ไปหน้าเข้างาน →"** มุมขวาบน

### ทุกเช้าก่อนเปิดร้าน (ก่อน 10:00)
1. เปิดหน้าเข้างาน — จะเห็นสองการ์ด: **💆 หมอนวด (x/6 มา)** และ **🧑‍💼 พนักงาน (x/2 มา)**
2. กดปุ่มเขียว **"เช็คอิน"** ให้ทุกคนที่มาทำงานวันนั้น (ทั้งหมอนวดและทีมงาน)
3. ดูวงแหวนสีหน้าชื่อให้ครบทุกแถว:

   | วงแหวน | ความหมาย | ต้องทำอะไร |
   | --- | --- | --- |
   | 🟢 เขียว | เช็คอินแล้ว (ใต้ชื่อบอกเวลาเข้า) | ไม่ต้องทำอะไร |
   | ⚪ เทา | วางแผนหยุด/ลาไว้ | ไม่ต้องติ๊ก |
   | 🔴 แดง | **ยังไม่เช็คอิน และไม่มีแผนหยุด** | เช็คว่ามาไหม → ถ้ามาให้ติ๊ก ถ้าไม่มาให้ไปลงที่หน้าจัดวันหยุด |
   | ⚪ เทา (กลุ่มพาร์ทไทม์) | เรียกเมื่อต้องการ — ไม่ได้เรียกวันนี้ | ไม่ต้องทำอะไร ถ้าเขามาก็กดเช็คอินได้เลย |

4. คนที่วางแผนหยุดไว้แต่**โผล่มาทำงานจริง** → กด "เช็คอิน" ทับได้เลย ระบบยอม
5. ติ๊กผิดคน → กดปุ่ม **"ยกเลิก"** (ปุ่มแดง)

### ตอนกลับบ้าน
กดปุ่ม **"ออกงาน"** ของคนนั้น เพื่อบันทึกเวลาออก — เวลานี้เอาไปคิดชั่วโมงทำงานในหน้าทีมงาน
(ถ้าไม่กด ระบบจะมีแต่เวลาเข้า ไม่มีเวลาออก)

### อย่างอื่นในหน้านี้
- ใต้ชื่อแต่ละคนบอก **"เดือนนี้มา X วัน"** ใช้เช็คคร่าวๆ ได้เลยว่าใครมาน้อย/มาก
- **เพิ่มพนักงานใหม่ (แบบเร็ว):** ท้ายการ์ดพนักงาน → พิมพ์ชื่อ → เลือกตำแหน่ง → กด **+ เพิ่ม**
- **ลูกศร ← →** ด้านบนเลื่อนดูวันอื่นได้ (เมื่อวาน / พรุ่งนี้)

### จัดการรายชื่อพนักงานเอง (ไม่ต้องแจ้งใคร)

ไปที่ **ตั้งค่า → แท็บ "พนักงาน"** ทำได้ครบในที่เดียว:

| อยากทำ | วิธี |
| --- | --- |
| เพิ่มคนใหม่ | กด **+ เพิ่มพนักงาน** → กรอกชื่อ → เลือกตำแหน่ง → บันทึก |
| เปลี่ยนตำแหน่ง / แก้ชื่อสะกดผิด | กด **แก้ไข** ที่ชื่อคนนั้น |
| **ตั้งตำแหน่งใหม่ที่ยังไม่มีในลิสต์** | ในช่องตำแหน่งเลือก **"+ เพิ่มตำแหน่งใหม่..."** แล้วพิมพ์เอง — ครั้งต่อไปตำแหน่งนี้จะอยู่ในลิสต์ให้เลือกเลย |
| **ตั้งเป็นพาร์ทไทม์** | กด **แก้ไข** → ติ๊ก **"พาร์ทไทม์ — เรียกเป็นครั้งคราว"** → บันทึก |
| **พนักงานลาออก** | กด **แก้ไข** → เลือก **"ลาออกแล้ว"** → บันทึก |
| คนเก่ากลับมาทำงาน | กด **แก้ไข** ที่กลุ่ม "ลาออกแล้ว" → เลือก **"ทำงานอยู่"** |

**พาร์ทไทม์ใช้เมื่อไหร่:** คนที่ยังอยู่กับร้านแต่ไม่ได้มาทุกวัน (เรียกเป็นครั้งคราว)
ติ๊กไว้แล้วเขาจะ **ไม่ถูกนับว่าขาดงาน** ในวันที่ไม่ได้เรียก — ชื่อย้ายไปอยู่กลุ่ม
"🕘 พาร์ทไทม์ — เรียกเป็นครั้งคราว" ท้ายหน้าเข้างาน วงแหวนเป็นเทาไม่ใช่แดง ไม่เข้าตัวหารของเลข (x/N มา)
และ **ไม่ต้องลงวันหยุดล่วงหน้าให้** (ชื่อจะไม่อยู่ในตารางจัดวันหยุด)
แต่วันไหนเขามาทำงานจริง **กดเช็คอินได้ตามปกติ** วันทำงานนับครบเหมือนเดิม

> อย่าใช้ "ลาออกแล้ว" กับพาร์ทไทม์ที่ยังเรียกอยู่ — ลาออกจะทำให้ชื่อหายจากหน้าเข้างาน
> วันที่เขามาจริงจะติ๊กไม่ได้ ต้องไปเปิดกลับก่อนทุกครั้ง เสี่ยงลืมแล้ววันทำงานหาย

**บันทึกลาออกแล้วเกิดอะไร:** ชื่อหายจากรายการติ๊กเข้างานและตารางจัดวันหยุดทันที
แต่**ประวัติเข้างานเดิมยังอยู่ครบ** ไม่ได้ลบ — รายงานย้อนหลังและการนับวันทำงานไม่เปลี่ยน
และกดกลับเป็น "ทำงานอยู่" ได้ทุกเมื่อ

> หมอนวดอยู่คนละแท็บ: **ตั้งค่า → หมอนวด** (เพิ่ม/แก้ชื่อ/บันทึกลาออก วิธีเดียวกันเป๊ะ)
> ระบบกันชื่อซ้ำให้แล้ว ถ้าพิมพ์ชื่อที่มีอยู่แล้วจะเตือนว่า "มีรายการชื่อนี้อยู่แล้ว"

### ถ้าไม่เช็คอินจะเกิดอะไร
- บอร์ด **คิววันนี้** แถวของหมอคนนั้นจะเป็น **ลายทแยง วางการ์ดคิวไม่ได้**
- ลูกค้าจองไลน์ **ไม่นับสลอตของหมอคนนั้น**
- หน้า **ทีมงาน** นับวันทำงานและชั่วโมงขาดไป กระทบการคิดค่าแรง

> **เคสจริงที่พลาดไปแล้ว:** วันที่ 27 ต.ค. 2569 ไม่มีใครเช็คอินเลยแม้แต่คนเดียว ทั้งที่ร้านเปิดและขายได้ 10 บิล 7,820 บาท — ทั้งวันนั้นหายไปจากสถิติวันทำงานของทุกคน

## 3. ⚠️ ข้อควรระวังที่สำคัญที่สุด — กฎการทับกันของสองระบบ

สำหรับวันในอนาคต ระบบคิดความจุรับจองแบบนี้:

```
ถ้าวันนั้น "มีคนเช็คอินไว้แล้วแม้แต่คนเดียว"
    → ความจุ = จำนวนคนที่เช็คอินไว้  (ไม่ดูแผนวันหยุดอีกเลย)
ถ้าวันนั้น "ยังไม่มีใครเช็คอิน"
    → ความจุ = หมอ active ทั้งหมด − คนที่วางแผนหยุด/ลา
```

**แปลว่า:** ถ้าเผลอติ๊กเช็คอินล่วงหน้าไว้แค่ 1 คนสำหรับวันพรุ่งนี้ ระบบจะคิดว่าพรุ่งนี้มีหมอแค่ 1 คน แล้วปิดรับจองเกือบทั้งวัน

**วิธีที่ถูกต้อง:**
- ✅ วันอนาคต → ลงที่หน้า **จัดวันหยุด** เท่านั้น (ลงแต่คนที่ไม่มา) — ปลอดภัยสุด
- ✅ ถ้าจะติ๊กเช็คอินล่วงหน้า (เช่นรู้แน่ชัดแล้วว่าพรุ่งนี้ใครมา) → **ต้องติ๊กให้ครบทุกคนที่จะมา** ไม่ติ๊กครึ่งๆ
- ❌ ห้ามติ๊กเช็คอินล่วงหน้าแค่บางคนแล้วทิ้งไว้

## 4. "พรุ่งนี้ใครมาทำงาน / คิวไหน" ดูที่ไหน

| อยากรู้ | เปิดหน้า |
| --- | --- |
| พรุ่งนี้ใครมา ใครหยุด | **เข้างาน** → กดลูกศร → (จะขึ้นคำว่า "พรุ่งนี้") |
| ภาพรวมทั้งเดือน + วันไหนคนบาง | **จัดวันหยุด** (ดูแถว "หมอทำงาน (คน)") |
| คิวจริง ใครนวดกี่โมง เตียงไหน | **คิววันนี้** (`/queue`) |
| ใครมาทำงานกี่วัน กี่ชั่วโมง เดือนนี้ | **ทีมงาน** |

**ข้อจำกัดที่ต้องรู้:** ระบบ **ยังไม่มีการแบ่งกะ** (ไม่มีกะเช้า/กะบ่าย) ทุกคนเป็นกะเดียวกันทั้งร้าน
เวลาจริงเฉลี่ยจากการเช็คอิน–ออกงาน = **10:00 – 21:35**
ถ้าอยากรู้ว่าใคร "คิวไหน" ในความหมายของรอบเวลา ต้องดูที่บอร์ดคิว ไม่ใช่ตารางวันหยุด

## 5. เช็คลิสต์ประจำวัน (พิมพ์แปะไว้ที่เคาน์เตอร์ได้)

**เช้า — ก่อนเปิดร้าน**
- [ ] เปิดหน้า **เข้างาน** ติ๊กเช็คอินทุกคนที่มา
- [ ] ไม่เหลือวงแหวนแดงที่ไม่มีคำอธิบาย

**เย็น — ก่อนปิดร้าน**
- [ ] กด **ออกงาน** ให้ทุกคน
- [ ] ถามทีมว่าพรุ่งนี้ใครไม่มา → ลงใน **จัดวันหยุด**

**อาทิตย์ — วางแผนสัปดาห์หน้า**
- [ ] เปิด **จัดวันหยุด** กดปุ่มคัดลอกสัปดาห์ แล้วแก้ที่ต่าง

## 6. เรื่องที่เจ้าของร้านควรจัดให้เรียบร้อยก่อนมอบงานนี้

1. **สิทธิ์เข้าหน้าจัดวันหยุด** — ตอนนี้เปิดให้เฉพาะ *ผู้จัดการ/แอดมิน* และพนักงานต้อนรับใช้บัญชีผู้จัดการร่วมกัน
   ผลคือชื่อผู้บันทึกขึ้นว่า "ผู้จัดการ" หมดทุกคน แยกไม่ออกว่าใครลง และบัญชีนั้นเห็นรายงานเงินทั้งหมดด้วย
   → ควรสร้างบัญชีระดับ *พนักงาน* แยกรายคน แล้วเปิดสิทธิ์หน้าจัดวันหยุดให้ระดับพนักงานลงได้ (แต่ไม่เห็นรายงานการเงิน)
2. **รายชื่อทีมงาน** — จัดให้แล้ว 4 พ.ย. 2569 ตามที่เจ้าของร้านยืนยัน (จากนี้ไปแก้เองได้ที่ ตั้งค่า → พนักงาน)
   - ✅ รวม "กี้ รีเซฟชั่น" ที่ซ้ำสองระเบียนเหลือระเบียนเดียว (ตัวที่มีประวัติเข้างาน) ตำแหน่ง **พนักงานต้อนรับ**
   - ✅ ปิดชื่อ "ดา" (ผู้จัดการ) และ "บี" (ผู้ช่วยผู้จัดการ) ที่ไม่ได้ทำงานแล้ว — ประวัติเข้างาน 58 และ 24 วันยังเก็บไว้ครบ
   - ✅ ตั้งตำแหน่ง **พนักงานต้อนรับ** ให้ทั้ง "กี้ รีเซฟชั่น" และ "บูม รีเซฟชั่น" (เดิมเป็น "อื่นๆ" ทั้งคู่)
   - ✅ ปิดชื่อ **ดาแม่บ้าน** (11 พ.ย. 2569) — ตัดเงินเดือนคาดหวัง 12,000 ออกจากหน้าค่ามือด้วย
   - ✅ ตั้ง **เค้ก พาทไทม์** เป็นพาร์ทไทม์ — เรียกเมื่อไหร่ก็เช็คอินได้ ไม่ขึ้นขาดงานในวันที่ไม่ได้เรียก

   ทีมงานที่ยังทำงานอยู่ตอนนี้: กี้ รีเซฟชั่น · บูม รีเซฟชั่น (ประจำ) · เค้ก พาทไทม์ (พาร์ทไทม์)
   - "ดา" (ผู้จัดการ) กับ "ดาแม่บ้าน" (แม่บ้าน) เป็นคนละคน ไม่ใช่ระเบียนซ้ำ — เดือน ก.ย. ติ๊กเข้างานพร้อมกันในวันเดียวกัน 23 วัน
3. **ตั้งกติกา "ลา" ให้ชัด** แล้วสอนให้ใช้ — ปัจจุบันไม่มีใครใช้เลย
4. **พฤศจิกายนยังว่างเกือบทั้งเดือน** (ลงไว้แค่ 2 คน 9 วัน) ควรลงให้ครบก่อนเริ่มใช้งานจริง
